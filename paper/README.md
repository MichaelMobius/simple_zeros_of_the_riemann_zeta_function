# Manuscript

This directory contains the submission-ready manuscript for

**A Position-Weighted Refinement for Simple Zeros of the Riemann Zeta Function**

by Michael Hurtado.

- `main.tex` — complete LaTeX source
- `main.pdf` — compiled manuscript

The submission-ready manuscript is frozen in release `v1.1.0-paper`.

The computer-assisted artifact used by the manuscript is independently
frozen in release `v1.0.0-paper` at commit `c57f53e`.

For certification and reproduction instructions, see:

`../certification/arb_256/README.md`
